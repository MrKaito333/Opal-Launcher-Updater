## 🌟 Make more of your game library

Opal Launcher consolidates your gaming universe into a single, cohesive ecosystem. No matter where your games live, they belong here.

- 🎮 **Unified Hub** – Keep all your owned games together and launch them instantly from one beautiful interface.
- 🔍 **Discover & Explore** – Dive into curated collections, smart recommendations, and comprehensive game pages.
- 📊 **Track Everything** – Monitor your playtime, unlock achievements, and stay connected with what your friends are playing.
- ☁️ **Safe Keeping** – Never lose a save file again with built-in cloud progress backup.
- 🎨 **Deep Customization** – Personalize your environment with custom artwork, UI themes, and a dynamic Big Picture view.
- 🕹️ **Emulation-Ready** – Easily manage your classic configurations and launch your favorite emulators side-by-side with modern titles.

## 📦 Platform & Installation Notes

* **Updates:** The Windows installer and Linux AppImage packages support automatic, in-launcher updates.
* **macOS Users:** Builds are currently unsigned. If the system blocks execution, right-click (or Control-click) the application file and select **Open** from the context menu.
* **Alternative Formats:** Need portable archives or specialized packaging? Explore [all releases](https://github.com/MrKaito333/Opal-Launcher-Updater/releases).

> [!IMPORTANT]  
> **Upgrading from v1.0.3?** Please manually install the latest build one final time to successfully migrate to our new public update stream. Your existing library configuration, progress, and settings will remain fully intact.
