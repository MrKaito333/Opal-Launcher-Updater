## Make more of your game library

Opal Launcher brings your games together in one place, wherever they live.

- **Unified hub:** keep every game you own together and launch it from one interface.
- **Discover and explore:** curated collections, recommendations and detailed game pages.
- **Downloads built in:** install your favorites or pull a fresh copy without leaving the launcher.
- **Track everything:** playtime, Steam stats and more.
- **Make it yours:** custom artwork, UI themes and a Big Picture mode for the couch.
- **Emulation-ready:** manage your classic setups and launch emulators next to modern titles.
- **Game runtimes sorted out (Windows):** Visual C++, DirectX, XNA, OpenAL and .NET installed from one place, with one permission prompt.

## Installing

| System  | Download                                                                                                                         | Updates                    |
| ------- | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| Windows | [`opal-launcher-setup.exe`](https://github.com/MrKaito333/Opal-Launcher-Updater/releases/latest/download/opal-launcher-setup.exe) | Automatic, in the launcher |
| macOS   | [`opal-launcher.dmg`](https://github.com/MrKaito333/Opal-Launcher-Updater/releases/latest/download/opal-launcher.dmg)             | Install each new version   |
| Linux   | [`opal-launcher.AppImage`](https://github.com/MrKaito333/Opal-Launcher-Updater/releases/latest/download/opal-launcher.AppImage)   | Automatic, in the launcher |

**Windows:** run the installer. Prefer no install? Use the [portable build](https://github.com/MrKaito333/Opal-Launcher-Updater/releases/latest/download/opal-launcher-portable.exe), which does not update itself.

**macOS:** open the disk image and drag Opal Launcher into Applications. The build is for Apple Silicon Macs and is not signed by Apple yet, so the first time, right-click (or Control-click) the app, choose **Open**, then confirm.

**Linux:** make the AppImage executable (`chmod +x opal-launcher.AppImage`) and run it. Prefer a package? `.deb`, `.rpm` and `.snap` files are on the [releases page](https://github.com/MrKaito333/Opal-Launcher-Updater/releases/latest).

Your library, collections and settings stay in place when you update.
