# Opal Launcher

Your games, saves, and discoveries in one place.

**[Windows](https://github.com/MrKaito333/Opal-Launcher-Updater/releases/latest/download/opal-launcher-setup.exe) | [Mac](https://github.com/MrKaito333/Opal-Launcher-Updater/releases/latest/download/opal-launcher.dmg) | [Linux](https://github.com/MrKaito333/Opal-Launcher-Updater/releases/latest/download/opal-launcher.AppImage)**

## Make more of your game library

- Keep the games you own together and launch them from one place.
- Explore curated collections, recommendations, and detailed game pages.
- Track playtime and achievements, and see what your friends are playing.
- Back up progress with cloud saves.
- Personalize your library with artwork, themes, and a Big Picture view.
- Manage downloads and set up emulators for classic games.

The buttons above download the newest published build for each platform. Windows setup and Linux AppImage installations support updates in the launcher. Mac builds are currently unsigned and may require opening through the macOS context menu. See [all releases](https://github.com/MrKaito333/Opal-Launcher-Updater/releases) for portable and other package formats.

If you have version 1.0.3, install the latest build manually once to switch to the new public update feed. Your library and settings stay in place.
